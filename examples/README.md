# pyrovue.json examples

Copy the one closest to your project to the root of your repository and change the commands.

| Folder | For |
| --- | --- |
| [`node-vite`](node-vite/pyrovue.json) | A Node.js app with a dev server |
| [`python-fastapi`](python-fastapi/pyrovue.json) | A Python API, with the preview opening its `/docs` page |
| [`frontend-backend`](frontend-backend/pyrovue.json) | A frontend in one folder and a backend in another, started together |
| [`cli-or-library`](cli-or-library/pyrovue.json) | A project with nothing to serve: it is installed and left ready in the terminal |

Most repositories don't need the file at all. Try the plain link first: `https://pyrovue.com/github.com/OWNER/REPO`.
